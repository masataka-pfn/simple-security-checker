# IOC 一覧ファイル

`ssc` の `ioc` チェックは、`checks.ioc.files`（既定は `/etc/ssc/ioc.d/*.txt`）の IOC を、ログと現在の接続と照合します。
脅威レポートが出たら、そこに載っている IOC を1ファイルにまとめて置くだけで、翌日から毎日照合されます。

## 書式

1行に1件書きます。`#` から後ろはコメントで、一致したときの表示に出典として出ます。

| 書き方 | 種類 | 照合する相手 |
| --- | --- | --- |
| `38.244.50[.]120` | IP（IPv4 / IPv6） | ログの全行、現在の接続（`ss`） |
| `xcai[.]pro` | ドメイン（サブドメインも一致） | ログの全行 |
| `hxxp://203.0.113.5:8080/x` | URL（ホスト部分を IP / ドメインとして扱う） | 同上 |
| `/.claude/settings.json` | パス | Web サーバーのアクセスログのリクエスト |

レポートの defang 表記（`[.]`、`(.)`、`[:]`、`hxxp`）はそのまま貼り付けて構いません。

## 判定

- IP / ドメインがログに新しく出現したら「要対応」、IOC の IP と通信中なら「要対応」です。
- パスへのリクエストは、成功応答（2xx）があれば「要対応」、なければ「要確認」です。
- 一度メールで報告したログの行は `state_dir/ioc_seen` に記録し、次回からは「既報」として数えません。
  記録するのは `ssc run` で実行したときだけで、`ssc check ioc` を手で実行しても記録は変わりません。
