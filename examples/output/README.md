# 出力のサンプル

`ssc` の出力の例です。行の書式は実際の出力と同じですが、ホスト名・IP アドレス・URL・パッケージ名とバージョン・CVE 番号・日時は説明用の架空のものです（IP は文書用のアドレス帯 `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`、パッケージは `libexample3` などの `example` を含む名前、CVE は `CVE-2026-999xx`）。実在のパッケージや脆弱性についての情報ではありません。

| ファイル | 内容 |
| --- | --- |
| [`security_updates.txt`](security_updates.txt) | セキュリティ更新のチェック。KEV に載った CVE（要対応）と、EPSS が高い CVE（要確認）がある例 |
| [`attack_surface.txt`](attack_surface.txt) | 攻撃点のチェック。nginx の `sites-enabled` に残ったバックアップと、基準にない SSH 公開鍵を見つけた例 |
| [`web_services.txt`](web_services.txt) | Web サービスの稼働確認。バックエンドのサービスがクラッシュループしている例 |
| [`ioc.txt`](ioc.txt) | IOC の照合。レポートに載ったパスへのリクエストが新たに見つかった例 |
| [`mail_security.txt`](mail_security.txt) | `ssc run security --dry-run` で見るメール。本文には要確認・要対応の行だけが載る |

## 見方

- 各行は `[OK]` / `[情報]` / `[要確認]` / `[要対応]` のどれかで始まります。件数に数えるのは `[要確認]` と `[要対応]` です。
- 最後のまとめの行（`要対応項目: N 件` か `問題なし — …`）で、`ssc run` がメールを送るかどうかと件名を決めます。
- メールの本文（`notify: always` 以外）は `--quiet` で作るので、`[OK]` と `[情報]` の行は省かれ、見出しだけが残ります。
  ただしディスク使用率と直近のログイン失敗件数のように、常に見ておきたい行は `[OK]` でも載せます。
- root 以外で実行すると、root が必要な項目は `[情報] …: root 権限が必要なためスキップ` となり、最初と最後に警告が出ます。
